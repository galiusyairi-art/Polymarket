# בוט פולימרקט

אתר שעוקב בכל שנייה אחרי ביטקוין, את'ריום וסולנה ומחפש מצבים שבהם המחיר בפולימרקט, בשווקים של "עולה או יורד ב-15 הדקות הקרובות", זול מהסיכוי האמיתי.

- **טאב סימולציה:** המערכת "מהמרת" בכסף מדומה במחירים האמיתיים של אותו רגע, ובודקת בעצמה אם האסטרטגיה מרוויחה.
- **טאב חי:** מסחר בכסף אמיתי. **נעול** עד שהסימולציה עוברת את כל בדיקות המוכנות, ונפתח מעצמו כשהיא עוברת.

## בדיקות המוכנות (כולן חייבות לעבור)
| בדיקה | דרישה |
|---|---|
| זמן הקלטה | לפחות 72 שעות |
| המחיר שלנו תואם להכרעת פולימרקט | לפחות 97% מ-100 חלונות לפחות |
| מספיק הימורים מדומים | לפחות 100 |
| רווח אחרי עמלות | לפחות +3% לכל דולר |
| לא סתם מזל | גם בתרחיש הפסימי (רווח ממוצע פחות טעות סטטיסטית) הרווח חיובי |
| עדיין עובד לאחרונה | 50 ההימורים האחרונים ברווח |

אם בדיקה נכשלת בזמן שהמסחר האמיתי פועל, המסחר **נכבה אוטומטית**.

## הגנות על כסף אמיתי
- סכום מקסימלי להימור ($50, ברירת מחדל $5) והגבלת הפסד יומית (ברירת מחדל $20). הכסף שנמצא בהימורים פתוחים נספר כאילו כבר הפסד.
- הזמנות מסוג "הכול או כלום" (FOK): אין הזמנות שנשארות תלויות.
- כפתור עצירת חירום.
- מפתח הארנק נשמר רק בשרת (משתנה סביבה) ולא עובר אף פעם בדפדפן.

## הפעלה על המחשב
צריך Python 3.10 ומעלה. ב-Mac לוחצים פעמיים על `start.command`, ובווינדוס על `start.bat`. האתר נפתח בדפדפן בכתובת http://localhost:8000.

ממסוף:
```bash
python3 -m polybot --check   # בדיקת חיבור חד-פעמית
python3 -m polybot           # הפעלה ופתיחת האתר
```

## הפעלה בשרת 24/7
**Render (מומלץ):** כל ההגדרות נמצאות ב-`render.yaml`. התקנה בלחיצה אחת:
https://render.com/deploy?repo=https://github.com/galiusyairi-art/Polymarket
Render יבקש סיסמה (`POLYBOT_PASSWORD`) ומפתח (רשות) ל-Claude. העלות: Starter כ-7 דולר לחודש, ועוד דיסק של 1GB בכ-0.25 דולר.

**Railway:** הקבצים `railway.json` ו-`Procfile` כבר מוכנים. בשרת מגדירים את משתני הסביבה הבאים:
- `POLYBOT_PASSWORD`: סיסמה לאתר (חובה, אחרת השרת לא עולה).
- `POLYBOT_DB=/data/polybot.sqlite`: ונפח (Volume) קבוע שמחובר ל-`/data`, כדי שהנתונים לא יימחקו.
- למסחר אמיתי בלבד: `POLYMARKET_PRIVATE_KEY`, ו-`POLYMARKET_FUNDER` (כתובת הארנק שמופיעה בפרופיל בפולימרקט).

## התראות במייל
מייל כשטרייד נפתח (עם הכרטיס והגרף), כשהוא נסגר (הרווח או ההפסד), וסיכום יומי ב-23:55. את הכתובת ואת סוגי המיילים קובעים בדשבורד.
בשרת צריך להגדיר את `SMTP_USER` (כתובת Gmail ששולחת) ואת `SMTP_PASSWORD` ("סיסמת אפליקציה" של Gmail). אפשר להשתמש גם בספק אחר, דרך `SMTP_HOST` ו-`SMTP_PORT`.

## מה אומת מול פולימרקט (אוקטובר 2026)
- שמות השווקים: `btc-updown-15m-<זמן פתיחה>` (קיימים גם שווקים של 5 דקות).
- **ההכרעה:** לפי ממוצע (TWAP) של 60 שניות ממחיר Chainlink, ולא לפי מחיר רגעי. המודל מחשב את הסיכוי לפי זה, כולל החלק של הדקה האחרונה שכבר "ננעל".
- העמלה נקראת מכל שוק (`feeSchedule`), וכן מינימום ההזמנה (5 מניות) ויחידת המחיר.
- השעון מסונכרן עם השרת של פולימרקט (פער של פחות משנייה).
- **המחיר:** מחיר Chainlink עצמו, בערוץ חי של פולימרקט (מגיע כשנייה אחרי שנקבע). ספר ההזמנות מגיע בערוץ חי, וכל עדכון נבדק תוך אלפיות שנייה. כשהנתונים לא עדכניים, המערכת לא מהמרת.
- **עדיין פתוח:** האם ההכרעה היא "ממוצע 60 שניות" או "מחיר בשנייה המדויקת". האתר מודד את שתי הקריאות מול התוצאות האמיתיות.
- שווקים קיימים (5 ו-15 דקות): BTC, ETH, SOL, XRP, DOGE, BNB, HYPE.

## הרצה מהמחשב שלך (מסחר בכסף אמיתי)

פולימרקט בודקת מאיזו מדינה יוצאות ההזמנות. השרת ב-Render נמצא בגרמניה, שחסומה, ולכן כסף אמיתי
צריך לרוץ ממחשב שנמצא במדינה שמותר לך לסחור ממנה. הסימולציה והמעבדה ממשיכות ב-Render כרגיל.

1. מתקינים Python 3.12 (python.org, לסמן "Add to PATH").
2. מורידים את הפרויקט מ-GitHub (Code ← Download ZIP) ופורסים לתיקייה.
3. מעתיקים את `polybot.env.example` לקובץ בשם `polybot.env` באותה תיקייה, וממלאים את המפתח
   ואת כתובת הארנק. הקובץ נשאר רק במחשב שלך ולא עולה ל-GitHub. לא שולחים אותו לאף אחד.
4. ב-Render: הגדרות ← מערכת ← "הורד טריידים ותוצאות". גוררים את קובץ ה-ZIP על `start.bat`:
   המחשב ממשיך בדיוק מאיפה שהשרת היה (אסטרטגיות, הגדרות, היסטוריה). בפעמים הבאות: לחיצה כפולה.
5. בדשבורד שנפתח: הגדרות ← כסף אמיתי ← "בדוק אזור" צריך להראות ✓ מותר. ואז מדליקים כסף אמיתי.

המחשב צריך להיות דלוק ומחובר, בלי מצב שינה. ב-Render לא מדליקים כסף אמיתי (שם הוא נכבה לבד).
