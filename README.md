# Polymarket Bot: שלב 1 (הקלטה ומסחר על נייר)

**אין כאן כסף אמיתי.** המערכת רק מסתכלת, מקליטה ורושמת "הימורים מדומים", כדי לבדוק אם הרעיון בכלל מרוויח.

## מה זה עושה
פולימרקט מציע שווקים קצרים של 15 דקות: "האם ביטקוין (או את'ריום, או סולנה) יסיים את החלון מעל או מתחת למחיר הפתיחה?".

כל שנייה המערכת עושה ארבעה דברים:
1. בודקת את המחיר הנוכחי (מ-Coinbase) וכמה זמן נשאר לחלון.
2. מחשבת מה הסיכוי **האמיתי** ל"עולה" (לפי כמה המחיר כבר זז ביחס לתנודתיות הרגילה).
3. משווה למחיר בפולימרקט. אם הוא זול מדי ביחס לסיכוי, אחרי עמלות, היא רושמת הימור מדומה במחירים שהיו באמת בספר ההזמנות.
4. כשהחלון נסגר, היא בודקת מה פולימרקט הכריע ומחשבת רווח או הפסד.

## הפעלה
צריך Python 3.10 ומעלה. אין ספריות להתקין.

```bash
python3 -m polybot.run --check   # בדיקת חיבור חד-פעמית
python3 -m polybot.run           # להשאיר לרוץ כמה ימים (Ctrl+C לעצירה)
python3 -m polybot.report        # לראות תוצאות (אפשר גם בזמן שזה רץ)
```

אפשרויות:
- `--assets btc,eth`: אילו מטבעות לעקוב.
- `--minutes 5`: חלונות של 5 דקות, אם קיימים.
- `--min-edge 0.08`: להמר רק על פער של 8 נקודות ומעלה.
- `--stake 20`: גודל ההימור המדומה בדולרים.

## איך קוראים את הדוח
- **Price feed check:** באיזה אחוז מהחלונות המחיר שלנו הסכים עם הכרעת פולימרקט. מתחת לכ-97% אי אפשר לסמוך על החישוב.
- **PAPER BETS:** ההימורים המדומים ורווח או הפסד.
- **PREDICTION ACCURACY:** מי מנבא טוב יותר, הנוסחה שלנו או המחיר בפולימרקט. אם פולימרקט טוב יותר, אין לנו יתרון.
- **WHAT-IF:** מה היה קורה עם ספי כניסה אחרים.

## הנחות שעדיין צריך לאמת מול הנתונים האמיתיים
- שמות השווקים בפולימרקט (`btc-updown-15m-<זמן פתיחה>`) ומבנה התשובות של ה-API.
- נוסחת העמלה (`polybot/config.py`). כדאי לוודא את הערכים העדכניים בתיעוד של פולימרקט.
- השווקים נסגרים לפי מחיר Chainlink ולא לפי Coinbase. הדוח מודד כמה זה משנה.
